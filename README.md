# Retail Sales Performance Dashboard

## 📌 Project Overview
The Retail Sales Performance Dashboard is an interactive business analytics project created using Microsoft Excel. It helps analyze retail sales data and visualize important business insights through KPI cards, charts, Pivot Tables, and interactive slicers.

## 🎯 Project Objectives
- Analyze overall sales and profit.
- Track monthly sales and profit trends.
- Compare region-wise sales performance.
- Analyze product category performance.
- Understand payment mode distribution.
- Provide interactive data filtering.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Slicers
- Data Visualization
- Business Analytics

## 📈 Dashboard Features
1. Monthly Sales & Profit Trend
2. Region-wise Sales & Profit Analysis
3. Product Category Performance
4. Payment Mode Analysis
5. Interactive Slicers for filtering data

## 📁 Dataset Information
- Dataset: Indian Retail Sales Dataset
- Total Records: 1,200
- Total Columns: 14

## 📂 Project Structure
- `Data/` – Contains the original CSV dataset.
- `Retail_Sales_Performance_Dashboard.xlsx` – Interactive Excel dashboard.
- `Retail_Sales_Performance_Dashboard1` – PDF version of the dashboard.
